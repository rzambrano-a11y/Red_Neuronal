Cómo funciona el experimento

La red aprende a separar conexiones simuladas en dos etiquetas: 0, normal, y 1, sospechosa. Esta pantalla no inventa el número: lo calcula el modelo entrenado.

Entradas y etiquetas

x₁ son los intentos fallidos de inicio de sesión, de 0 a 20. x₂ es el tráfico enviado, de 0 a 2.000 MB. La semilla 42 solo permite repetir el experimento; no clasifica conexiones.

puntaje = 0,55 × (intentos / 20) + 0,45 × (tráfico / 2000) + ruido
etiqueta = 1 si puntaje ≥ 0,55; si no, 0

Dentro de una neurona

z = (w₁ × x₁) + (w₂ × x₂) + b
ReLU(z) = 0 si z < 0;  z si z ≥ 0
p = 1 / (1 + e^(−z))

Los pesos dicen cuánto importa cada entrada. Los sesgos desplazan la respuesta. ReLU, en las capas ocultas, permite relaciones que una recta no separa. La sigmoide de la salida convierte la cuenta en una probabilidad entre 0 y 1. Si llega a 0,5, la clase es sospechosa.

Dónde aprende

El aprendizaje ocurre en modelo.fit(): propagación hacia adelante, comparación con la etiqueta, pérdida y ajuste de pesos y sesgos. El 64 % ajusta, el 16 % vigila la parada y el 20 % queda intacto para la pérdida, la exactitud, la precisión y el recall. Hay 65 parámetros entrenables.

La interfaz llama a ConnectionRiskService.predict. El servicio valida el rango, normaliza con el escalador del entrenamiento y devuelve la probabilidad, el umbral, la clase y la explicación.
